# ML-based-prediction-and-optimization-of-compressive-strength-of-OPS-OPBC-lightweight-concrete
OPS/OPBC Concrete Mix Design Optimiser
XGBoost surrogate + GA / MFO / GA+MFO Hybrid

HOW TO RUN:
  1. Install Python or Anaconda Nevigator
  2. Put this file and Input_output_dataset.csv in the SAME folder
  3. Open in terminal in same folder
  4. Install: pip install flask xgboost scikit-learn deap numpy pandas
  5. Run:     python mix_design_gui.py
  6. Open:    http://127.0.0.1:5000
